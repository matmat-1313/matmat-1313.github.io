Données & respect de la vie privée

Politique de confidentialité.

À personnaliser avant mise en ligne

Cette page décrit le fonctionnement prévu du modèle. Vérifiez-la selon les services réellement utilisés, les données collectées et les règles applicables à l’association.

Fonctionnement du site

Ce site est conçu comme un site statique hébergé sur GitHub Pages. Dans cette version, le site ne contient ni compte utilisateur, ni base de données, ni formulaire de collecte connecté. Le formulaire de contact prépare un message dans le logiciel de messagerie du visiteur ; le site ne reçoit donc pas directement ce message.

Données personnelles

Ne publiez pas de données personnelles sans base légale et autorisation appropriées. Évitez notamment les adresses privées, coordonnées personnelles, documents administratifs et informations concernant des personnes vivantes dans les arbres généalogiques ou les archives publiées.

Photographies et droit à l’image

Avant publication, vérifiez les droits d’auteur et, lorsque cela est nécessaire, obtenez l’autorisation des personnes reconnaissables. Soyez particulièrement prudent pour les mineurs. Privilégiez les photos dont l’association détient les droits ou pour lesquelles elle dispose d’une autorisation documentée.

Hébergement et journaux techniques

L’hébergeur peut traiter certaines données techniques nécessaires à la fourniture et à la sécurité du service. Consultez les documents de confidentialité de GitHub et indiquez ici les informations adaptées à la configuration effectivement utilisée.

Contact et droits

Pour toute demande concernant les données personnelles, contactez le responsable désigné par l’association à l’adresse officielle publiée dans les mentions légales : l’adresse e-mail officielle à renseigner dans contact.html et les mentions légales. Complétez cette page avec les coordonnées du responsable de traitement, les finalités, bases légales, durées de conservation et modalités d’exercice des droits correspondant aux traitements réels.
